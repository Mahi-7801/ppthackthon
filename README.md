- `presentation.html`: Full 10-slide responsive Cyber-Glassmorphism web application slide deck.
- `generate_pptx.py`: Python script powered by `python-pptx` to programmatically build widescreen 16:9 PowerPoint presentations.

## 💻 How to Run & Generate Decks

### 1. View Interactive Web Presentation
Open `presentation.html` in any web browser. Keyboard shortcuts:
- `→` / `Spacebar`: Next slide (Instant 0ms transition)
- `←`: Previous slide
- `F`: Fullscreen mode

### 2. Generate PowerPoint (.pptx) Decks
```bash
pip install python-pptx
python generate_pptx.py
```
