Problem Statement 02 / 10

🚨 The Mobile Signing Bottleneck

  • Desktop Dependency: 90%+ of Class-3 DSC USB dongles require Windows/macOS drivers (ePass2003, HYP2003, Watchdata).
  • No Mobile USB Stack: Android/iOS apps cannot natively talk to physical CCID smart cards without native low-level wrappers.
  • Field Operations Broken: Field officers, executives, and citizens are forced back to desktop PCs to sign official PDFs.
  • Compliance Barriers: Cloud OTP signing often breaches key ownership requirements under Indian CCA rules.
Solution Overview 03 / 10

✨ Plug & Sign Solution

  • Direct USB-C CCID Driver: Plug any standard Type-C DSC dongle directly into Android/iOS phones to sign in seconds.
  • Zero Middleware: Native Kotlin USB Host API + iOS CryptoTokenKit bridge handles raw APDU smart card commands.
  • Hybrid WebView JS Bridge: Drop-in JavaScript bridge lets legacy government web portals trigger USB signing inside mobile apps.
  • Tamper-Evident Signatures: Complete PAdES/CAdES container assembly with RFC 3161 Timestamp Authority (TSA) proof.

🔄 End-to-End Signing Workflow & User Journey

HomeScreen — 🔌 USB Token Auto-Detection

Plug Type-C dongle ➔ Native Kotlin `CcidTransport` auto-detects USB smart card chip.

2

PINEntryScreen — 🔐 Secure Memory-Wiped PIN Entry

PIN passed directly to card buffer over APDU; byte array purged from RAM post-execution.

Security & Defense-In-Depth 07 / 10
Multi-Layer Security Architecture
Hardware Key Isolation, Zero-Memory Retention & Cryptographic Sealing

🔒 Hardware Security Engine

  • • On-Chip Key Isolation: Private RSA 2048 / ECC keys are physically non-exportable hardware assets inside silicon.
  • • In-Memory PIN Zeroization: Sensitive PIN byte arrays are purged from application RAM immediately after APDU execution.
  • • 3-Attempt Lockout Enforcement: App respects physical token policy and hard-locks after 3 wrong attempts.

🛡️ Data & Cryptographic Sealing

  • • SHA-256 Hashing Standard: Standardized collision-resistant cryptographic digest for all target documents.
  • • RFC 3161 TSA Timestamp: Cryptographically verifiable proof from CCA-approved Timestamp Authority.
  • • PostgreSQL Row-Level Security (RLS): User-isolated audit trail database policies with serial & IP tracking.
Developer Integration 08 / 10

🌐 Hybrid Mobile WebView JavaScript Bridge

Existing state government portals call `window.DSCSigning` to trigger physical Type-C USB signing inside mobile WebViews: 

window.DSCSigning.signDocument({
  documentHash: "a4f8e91c2b...",
  algorithm: "SHA256WithRSA"
}).then(signature => {
  console.log("Signed Hex:", signature.signature);
});
